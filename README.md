## 📖 Project Overview

**Amazon.in Clone** is a client-side e-commerce web application replicating the core shopping experience of Amazon India. Built purely with modular Vanilla JavaScript and custom CSS without external frameworks, it features real-time product search, multi-criteria filtering and sorting, interactive shopping cart management with automated tax calculation, wishlist persistence, user authentication with protected checkout routing, and a global Dark/Light theme toggle. All application state—including registered users, active sessions, cart items, wishlists, and theme preferences—persists across browser sessions via `localStorage`.
